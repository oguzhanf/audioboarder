# AudioBoarder Whiteboard (embedded Excalidraw)

This folder is the **source** for the live, hand-drawn whiteboard shown in the app's
central canvas. It builds a fully self-contained, **offline** [Excalidraw](https://github.com/excalidraw/excalidraw)
bundle that the WPF app hosts inside a `WebView2` control (`ExcalidrawCanvas`).

## How it fits together

```
SceneGraph  ──►  SceneToExcalidrawConverter (C#, AudioBoarder.Core)  ──►  .excalidraw JSON
                                                                              │
                                  ExcalidrawCanvas (WebView2)  ◄── PostWebMessageAsString
                                                                              │
                                  index.html + main.jsx  ──►  excalidrawAPI.updateScene(...)
```

- The C# side never renders the diagram itself for the whiteboard — it serialises the
  scene to the `.excalidraw` format and pushes it to Excalidraw, which draws it with its
  real Rough.js hand-drawn engine and the Excalifont/Virgil fonts.
- The same converter powers **File ▸ Export Excalidraw**, producing files the customer can
  open and keep editing in any Excalidraw instance.

## Build the vendored bundle

The built output lives in `../Assets/web` and **is committed** (it ships with the app).
`node_modules/` and `public/fonts/` are local-only and regenerated by the build script.

```powershell
pwsh -File .\build-bundle.ps1
```

This installs deps, copies Excalidraw's production fonts (for offline self-hosting),
and runs `vite build` into `../Assets/web`. The app's `.csproj` copies `Assets/web/**`
to the output directory; `ExcalidrawCanvas` maps it to the `https://audioboarder.local/`
virtual host.

## Verify the bundle (optional)

Renders the bundle in headless Edge (the same engine WebView2 uses), pushes a sample
scene, and screenshots it:

```powershell
npm run preview            # serves ../Assets/web at http://localhost:5566
node verify.cjs "http://localhost:5566/" <path-to-sample.excalidraw> verify.png
```

## Notes

- `EXCALIDRAW_ASSET_PATH` is set to `/` in `src/main.jsx`; fonts are served from
  `/fonts` (copied into `public/fonts` at build time).
- `base: "./"` in `vite.config.js` keeps every asset reference relative so the bundle
  works under the WebView2 virtual-host mapping.
- Bump Excalidraw by changing the version in `package.json` and re-running `build-bundle.ps1`.
